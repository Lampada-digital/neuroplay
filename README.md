# NEUROPLAY
**Aprender brincando, explorando e criando.**

## Como executar
1. Abra `index.html` no navegador
2. Clique em "Criar conta"
3. Pronto!

## Recursos
- 15 jogos educativos
- Biblioteca de histórias com narração
- Digitação (6 níveis)
- Música (instrumentos virtuais)
- Mundo dos animais
- Dashboards (Aluno, Pais, Professor, Admin)
- Acessibilidade completa
- PWA instalável
