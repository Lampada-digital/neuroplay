# NeuroPlay
**Aprender brincando, respeitando cada maneira de aprender.**

Plataforma web educacional offline com jogos e atividades para crianças e adolescentes neurodivergentes.

## Como executar
1. Abra `index.html` no navegador.
2. Pronto! Funciona 100% offline.

## Perfis
- **Aluno:** joga, ganha estrelas, vê conquistas.
- **Professor:** cadastra alunos, turmas, gera relatórios.
- **Administrador:** gerencia a plataforma.

## Jogos inclusos (15+)
Memória, Encontre o Objeto, Sequência de Cores, Sequência Numérica,
Número/Quantidade, Formas, Quebra-Cabeça, Diferenças, Associação Imagem/Palavra,
Formação de Palavras, Matemática, Classificação, Labirinto, Emoções, Sequência Lógica.
